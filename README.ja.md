## この研究が示すこと

隠れ状態から読み取れる情報と、個々の介入から支持される因果的な結論を分けて調べる。
絵文字をテキストのみの統制された事例として扱い、CLDRキーワードは語彙的な目標とする。
人間による意味の正解ラベルとしては扱わない。

- **キーワード検索（T19-L）:** 事前指定した9つのモデル・トークナイザ構成で、
  raw絵文字はコードポイント表記より、正式名と単語が重ならないCLDRキーワードをよく検索した。
  指定した無制約解析と、4表記のトークン数の組を項目間で厳密に一致させた解析で成立し、主要な部分結合検定の
  p値は0.0027だった。
- **固定・最適化部分空間への介入（T19-C/T20-C）:** 調べたrank-8の説明は、必要性と十分性を
  組み合わせた基準を満たさなかった。最適化した検査は、主要2部位とも較正不能だった。
  あらゆる低ランクの説明を否定する結果ではない。
- **読み出し状態を置換した後のattention経路への介入（T21-C）:** 195項目で、指定した状態置換の
  もとでは絵文字位置からの情報がキーワードのコサイン・マージンに寄与した。同時区間の下限は
  5つすべて正だったが、絶対的な情報の破壊・回復による平均top-1効果は0だった。
- **テキストのみの読み出し適格性検査:** 著者が作成した32の事実について、保留検査の
  直接質問・最小回答は88/96正答、A/B回答は104/192正答だった。事前指定した要件は両方とも
  未達。文脈内の絵文字解釈を論じる前に、質問と回答形式が測定の重要な制約として残る。

描画されたグリフの知覚、独立した人間による意味の妥当性、通常の生成応答を支える機構は
確立していない。

## 証拠資料と再計算

版を固定した資料は[`releases/v1.0.0/`](releases/v1.0.0/)に置く。
収録物、除外物、依存関係、過去の実験の再計算範囲は
[公開・再計算の案内](releases/v1.0.0/paper/PUBLIC_RELEASE_20261015.ja.md)を参照。
資料のハッシュを検査し、新しい適格性検査の保存済み得点を再計算するには、次を実行する。

```bash
cd releases/v1.0.0
python3 -S -B paper/scripts/build_public_release_20261015.py verify .
```

Python標準ライブラリだけで保存済み得点を2つの実装により検算し、モデルは実行しない。
GPUロジットを再取得する検査ではない。固定・最適化部分空間の結果は要約の提供にとどまり、
項目別推論の完全な再計算には対応しない。著者の個別回答、モデル・トークナイザの重み等は
含めない。

このリポジトリは、公開対象を明示的に選んだ独立の資料集であり、元のprivateリポジトリや
その全ソース履歴のミラーではない。元の履歴はここで公開しない。検証時には版を固定した
資料の内容を変更しないこと。
